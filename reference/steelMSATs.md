# Siletz Steelhead microsatellite snpRdata

Contains example data for 13 microsatellite loci from 1573 steelhead
from the Siletz river, Oregon, USA. Samples come from both the summer
and winter run wild and hatchery populations. For more details, see
Hemstrom et al 2018.

## Usage

``` r
steelMSATs
```

## Format

An object of class `snpRdata` with 13 rows and 1574 columns.

## Details

Sample metadata can be found using the `sample.meta` function.
Individuals have been randomly sorted into "families" for example
purposes.
