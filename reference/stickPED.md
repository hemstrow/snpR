# An artificial pedigree from the stickleback dataset.

Contains an artificially constructed pedigree based on the
[`stickSNPs`](https://hemstrow.github.io/snpR/reference/stickSNPs.md)
dataset. Here samples named 1 through 420 represent the sequenced
individuals in the
[`stickSNPs`](https://hemstrow.github.io/snpR/reference/stickSNPs.md)
dataset and individuals inferred via pedigree construction are affixed
with "f" or "m".

## Usage

``` r
stickPED
```

## Format

An object of class `data.frame` with 426 rows and 3 columns.
