# Calculate the proportion of polymorphic loci.

Calculates the proportion of polymorphic (genotyped) loci for any
combination of SNP and sample facets. Note: per window counts of
polymorphic loci can be calculated using
[`calc_tajimas_d`](https://hemstrow.github.io/snpR/reference/calc_tajimas_d.md).

## Usage

``` r
calc_prop_poly(x, facets = NULL)
```

## Arguments

- x:

  snpRdata object

- facets:

  facets over which to check for polymorphic loci. Can be any
  combination of SNP/sample facets. See
  [`Facets_in_snpR`](https://hemstrow.github.io/snpR/reference/Facets_in_snpR.md)
  for details.

## Value

A snpRdata object with prop_poly merged into the weighted.means slot.

## Details

Note that per window counts of polymorphic loci can be calculated using
[`calc_tajimas_d`](https://hemstrow.github.io/snpR/reference/calc_tajimas_d.md)
(contained in the `num_seg` column). Dividing this by the `n_snps`
column will return the proportion of polymorphic loci in each window if
that is desired!

x <- calc_prop_poly(stickSNPs)
